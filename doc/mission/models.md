# 当前模型：拟合方法与调用合同

当前模型是随仓库发布的唯一模型基线，包含 ASAP7 和 Nangate45 工艺参数。参数仍保留内部 schema、来源身份和诊断标记；这些机器字段不代表可供切换的多个发布模型。后续扩展从当前冻结资源开始。

模型用于离线软件预测。正常生成不读取应用实测标签，不进行精确实例查价，也不在线调用物理后端。原始任务中的全部算法和当前参数的覆盖范围应分别理解。

## 资源与职责

以下路径相对于 `vullib/models/autopipe/`：

| 文件 | 职责 |
| --- | --- |
| `asap7/response.json` | ASAP7 算术、G、S/control、shared 及完整诊断计价参数 |
| `asap7/characterization.json` | ASAP7 采样外壳有效本体窗口合同 |
| `nangate45/arithmetic.json` | Nangate45 Mul、Add/ADC、G 的离线响应与参考资源身份 |
| `nangate45/state-shared.json` | Nangate45 S、控制、shared 和实际边界参数 |
| `nangate45/characterization.json` | Nangate45 本体预算与采样周期换算合同 |
| `nangate45/cell-cover.json` | Nangate45 功能逻辑使用的合法单元覆盖面积 |
| `nangate45/package.json` | 工艺、阶段、子资源身份、适用范围和资格入口 |
| `profiles/*.json` | 工艺与测量流程身份 |
| `fixed_op_width_v1.json` | B/C 抽象静态权重，属于规则表，不是拟合后的物理响应 |

| `manifest.json` | 发布资源的字节哈希清单 |

入口是[资源加载](../../tools/autopipe/resources.py)的 `runtime(platform)`。它核对资源清单后，返回相应工艺的完整评价和优化接口。

## 数据与标签

模型拟合首先固定 RTL、工具、工艺、驱动／负载、SDC、ABC 目标以及提取阶段。当前参数的主要物理口径为 GRT；最终详细布线、其他修复预算或其他角的标签不能直接混作同一种训练数据。

算术本体标签取独占 producer 或整个 G 区域的内部组合延迟和面积。采样 FF、observer、控制与 physical-only 单元按各自责任分开。完整 Q→D 路径和整壳 Tmin 不能直接冒充本体标签。

以数值位宽、结果需求、常量／别名、carry、capture、负载和真实消费者描述样本。拟合同类共享函数，不为某个应用、精确位宽或请求点建立专价。在线特征必须能从编译图、请求和冻结资源得到；映射单元数、坐标、实测 slack 等只用于离线建模或诊断。

训练职责以源／producer 结构分组，同源的不同 T 或负载变体需要共同检查，不能仅按请求行随机拆分。训练拟合、验证选模、冻结后测试及已消费回归分别记录。完整应用的后端结果用于评价，不能再作为未见数据反馈到当前模型。

## 共享响应形式

当前运行时使用参数文件声明的具体特征和连接函数，主要形式如下：

```text
线性响应：y = intercept + Σ c_j · x_j
中心化响应：z_j = (x_j - center_j) / scale_j
正值响应：y = exp(intercept + Σ c_j · z_j)
参考工作量修正：y = reference(x) · 正值响应(x)
```

中心和尺度只由训练数据得到并随系数冻结。[响应实现](../../tools/autopipe/centered_response.py)检查特征维度、有限数值和正尺度，使用稳定求和。某些族继承线性函数，某些量采用正值参考修正，不能统一改成一个未经验证的多项式。

### 算术本体

ASAP7 的[算术计价](../../tools/autopipe/workload_diagnostic.py)按共享类型消费 producer 与消费者上下文：

- Mul：使用有效输入、已知位、结果保留范围及部分积工作量等特征；继承共享线性时延与面积响应。
- Add/ADC：时延沿用共享算术响应；面积使用合法 Boolean 单元覆盖 `cover_area` 乘中心化正值修正。
- Mux：时延使用覆盖工作量、请求压力与 capture 等特征的正值响应；面积沿用共享响应。
- Sub、Compare 等辅助算术沿继承的共享函数计价；预算适配或边界外推会保留诊断标记，不能据此扩张精度资格。

特征包含存活输入位、动态结果位、结果形状、重叠、carry、消费者算术宽度、引脚使用、负载分布和请求压力。Add 面积还消费覆盖、语义扇出、修复压力和锥跨度等可计算特征。

拟合做法是从相容训练源提取实际计价使用的特征，分别拟合延迟和面积；参考修正拟合实际标签与参考工作量的比值。正值响应在对数域以源均衡的回归／正则化方法求系数，候选特征和正则强度在训练内部留源评价或预声明的验证协议中选择。继承参数与后续修正的资产身份一同冻结。

运行时保留统一数值下限和已知一部分积工作量处理。证明为常量、连线别名或经 Boolean 化简为零工作时可给零算术价格；这需要语义证明，不能因模型无覆盖而给零。

### G：归约／融合区域

G 对整个归约区域计价。输入是实际 terms、位列、输出形状、共享输入关系和消费者等上下文，而不是只给“项数×位宽”。

其几何特征由 word 压缩 DAG、FA/HA 工作量、常量消简、存活输出、最终前缀工作量、深度及跨度等构造。同类不同宽度和稀疏形状共享参数。

当前 ASAP7 的 G 面积以 `ks_fused_area` 为参考乘正值响应；时延直接使用中心化正值响应。训练按源均衡；先检查几何与标签归属，再拟合残差和进行留源／验证评价，不能把 S 或边界误差交给 G 补偿。

区域内部 Add 等成员不再次收费或分配独立预算。G 是归约模型，不是能够自动吸收任意区域间布线和所有组合误差的万能项。

### S：状态面积与控制边界

S 投影分为 `input_service`、`native_state`、`external_state`。面积按数据位、信号数、valid 位、enable 域和 reset-one 位等特征进行线性计价；已有面积拟合资产随当前模型冻结。

控制响应分为 `native_enable`、`native_valid`、`input_valid`、`external_valid` 四类。特征包括逻辑 sink 负载、全局 FF、enabled words、原生 launch、两侧 reset 比例以及连续目标周期及其交互项。

当前完整控制响应使用每类一个固定岭回归：只读训练行，同 fold 总权重相等，对目标延迟取对数，按训练均值／尺度中心化；截距不惩罚，源均衡平方损失中的正则系数为 1。Nangate45 复用相同拟合规则，消费该工艺已经物化的特征。训练内误差保留为诊断，不冒称独立验证。

输出应同时保留逐控制源和消费者取 max 后的银行误差。少数源的保护漏点不能被平均值掩盖；名义数据位、编译器变量位和映射 FF 数也不能混用。

实际 reset／输入写使能以及端口边界有单独检查。当前部分控制路径使用代理与外推，因此完整功能正确和模型精度资格是不同结论。

### shared 与其他功能逻辑

shared 包括共享时钟、共享物理开销及 root repair。当前响应使用全局 FF、其平方根、预测功能面积、请求压力、输入位／端口、reset-one 位等线性特征。

shared 面积按真实设计加一次，不能按每个算子复制。算术以外的逻辑使用实际局部 Boolean DAG 和合法库单元覆盖，保留常量与共享关系；其时延仍属于诊断估计。

当前参数继承的状态面积、shared、数据边界与裕量是已冻结资产；重新拟合需要找回对应数据、特征及提取协议，不能仅从最终总面积反推各项。

### 采样窗口与等效周期

两套工艺分别保存 `characterization.json`，其家族合同包含 `alpha` 和 `H_char_ps`。它来源于相容采样外壳与离线边界，不是新增的整机时钟，也不是在线重跑综合。

完整换算为：

```text
B_char,v(T) = min_p(alpha_p · T - H_char,p - D_other,char,p(T))
B_char,v(T_eq,v) ≈ b_v
查询周期为 tau_v，模型返回实际预测 d_hat_v 和 A_hat_v
```

有消费者时使用其相容价格构造窗口；多个端点共同取紧。采样边界只用于换算，完整设计只加入实际边界和状态一次。某些辅助算术复用边界时保留外推标记。

当前发布合同中的家族覆盖、来源审计、`qualified` 和 `precision_validation_pending` 是边界信息。反解成功只能证明找到匹配窗口，不代表嵌入实现的精度已经通过。

## Nangate45 工艺适配

Nangate45 按本后端标签重新标定。相同 producer 的 RTL、三档请求及已有 ASAP7 标签先组成配对，保持本体所有权口径；ns 转 ps 等单位转换在提取时处理。

有限候选先比较全局比例、类型比例、类型仿射，再对缩放不足的量使用共享特征修正。参考函数以 `T / time_scale` 查询，修正项可消费数值宽度、工作量、请求、负载、carry、已知位和 `width_clock` 交互。训练拟合参数，按登记协议选择形式及请求轴缩放；对明确失败项作有记录的有限重拟合。

当前参数实际采用：

| 量 | 响应形式 | 参考查询的 `time_scale` |
| --- | --- | ---: |
| Mul 时延 | 全局缩放 | 2 |
| Mul 面积 | 全局缩放 | 1 |
| Add/ADC 时延 | 共享对数特征岭修正 | 0.5 |
| Add/ADC 面积 | 共享对数特征岭修正 | 2 |
| G 时延 | 全局缩放 | 0.5 |
| G 面积 | 全局缩放 | 2 |

比例和回归系数直接读取参数文件，不在说明中复制维护。Add/ADC 的修正形如 `reference(T / time_scale) × exp(β0 + Σ βj zj)`。

Nangate45 使用 ASAP7 响应作为已冻结参考基函数，并使用本工艺的 S/shared、采样边界与功能覆盖单元。这是当前模型的组合依赖，不是可以删除的旧模型回退。

拟合与组合评价主要服务 MAC32、Add512、Mul128；状态规模及请求域外会外推。G 的工程接入曾获允许，但原精度门槛未自动变为通过；`precision_qualified=false` 等参数标记继续有效。

## 精度与数据职责

当前模型保留诊断资格。S 的部分控制边界、Add/Mux/G 的部分源、宽／深状态与嵌入响应存在误差或外推限制；不能以完整候选可计价替代独立精度验收。

按源统计的 median/P95、逐路径误差、银行最大值、单个应用误差以及功能正确性分别报告。后续修复不得把已消费的测试数据重新称为未见测试，或根据某个应用结果增加专属价格。

当前预测回归保存 13 个完整候选，覆盖两种工艺及 C 所选配置，并禁止计价过程中读取外部标签或启动子进程。它验证数值与依赖稳定，不等于新增物理泛化评价。

## 重新拟合与扩展

发布仓库提供当前参数、推理、候选生成和软件验证；完整采样／训练驱动、训练集和物理证据保存在仓库外研究归档，不能把 `generate` 命令写成重新拟合命令。

历史拟合方法可追溯到归档中的 `workload_diagnostic.py`（完整 S 控制响应及包组装）、`nangate45_fit.py`、`nangate45_refit_fit.py`、`nangate45_pipeline_fit.py` 和 `nangate45_pipeline_fit_adapter.py`；`centered_response.py` 定义中心化响应的数值推理。重新使用前必须核对对应的数据、配置、参数身份和依赖，历史脚本不是当前发布的训练 CLI。

扩展时按以下顺序维护当前基线：

1. 记录 Git、子模块、资源清单与当前预测回归，确定要改的是特征、参数、边界合同还是搜索算法。
2. 固定可计算 Query、算术语义、所有权、采样外壳、流程和标签端点；新输入需要新合同，不能只增加几个系数。
3. 登记源分组和 train／validation／test 角色，先验证可测性、单位、功能与计价守恒，再采集并拟合。
4. 新参数写入独立目录，与当前模型比较组件误差、完整候选误差、排序和软件行为；仅有训练误差下降不足以替换。
5. 确认发布后统一更新参数引用、采样合同、profile、资源清单、范围标记和回归。保留修复前反例及原基线以便对照。

历史来源或 schema 字符串即使包含旧命名，也作为机器身份保留。文档统一称当前模型；不通过批量改 JSON 字符串来重命名模型。

使用命令见[生成与测试指南](../autopipe.md)，预算和完整选择见[当前实现](implementation.md)。
