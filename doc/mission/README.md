# 自动算术拆分与流水线化：维护文档

本目录说明当前项目的研究目标、已发布实现、模型方法和维护注意事项。论文工作及本轮实验整理已结束；这里不维护实验队列、资源排程或下一轮研究计划。

项目统一使用“**当前模型**”指随仓库发布、经过资源清单绑定的模型及其工艺参数。后续扩展和优化从当前冻结模型开始，保留原参数与预测回归作为对照。已停用方案不再作为可选模型或待办保留。

## 当前资产

| 路径 | 内容 |
| --- | --- |
| `tools/vulrtlgen.cpp` | VUL RTL 生成命令行入口 |

| `tools/autopipe/tests/` | 已保存的模型预测与资源身份回归 |
| `regression/generator_autopipe*.py` | VUL 集成、功能与候选一致性检查 |
| `rtlzz/` | C++ 编译器子模块 |

当前模型包含 ASAP7 和 Nangate45 工艺参数；两者的适用范围、拟合方式和资格应分别解释。当前资源保留诊断和外推标记，实验完成不等于全部组件或全部候选获得精度资格。

## 维护基线

- 开始修改前记录当前 Git 提交、子模块身份及 `vullib/models/autopipe/manifest.json`；以实际检出内容为准。
- 模型加载和生成不依赖历史 `experiments/`、服务器脚本或后端数据库。
- 参数 JSON 的内部 schema、历史身份字段、哈希及仍在使用的源码文件名属于兼容接口，保留原值。面向读者的说明统一称“当前模型”。
- 工程提速先验证候选、预测和选择结果保持一致；行为修复或搜索策略变化另行说明，不能用删除候选冒充等价提速。
- 新拟合先保存独立输出和评价，当前参数在确认替换前继续作为回归基线。发布时同步更新参数、合同、资源清单和测试。
