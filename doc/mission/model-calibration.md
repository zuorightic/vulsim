# AutoPipe 模型校准计划与记录

## 第一轮算术本体

对 Add/ADC、Sub/SBB、Mul、Compare 和数据 Mux 做 8–512 位周期扫描。建议从 8、12、16、24、32、48、64、96、128、192、256、384、512 位起步。基础样本采用等宽动态操作数，保留 Add/ADC 的进位、Sub/SBB 的借位和 Compare 的等值及顺序谓词。再选代表宽度补入不等宽、截断、常量位，以及不同的寄存器捕获和下游消费者。位宽记录输入、运算和实际保留结果三个口径。

每个选定的 RTL 结构在每套工艺下扫描 **15 个不同的请求周期**，宽松、适合、紧凑各 5 个。先用已有相容结果或少量试测找出采样外壳由 setup 违约转入接近达标的周期区间，再登记三档的具体 ps 值。

| 周期档 | 点数 | 取点依据 |
| --- | ---: | --- |
| 紧凑 | 5 | 从明显受时序压力到接近达标，覆盖映射和修复响应。 |
| 适合 | 5 | 围绕实测 setup 临界区，在边界两侧加密。 |
| 宽松 | 5 | 从已有稳定余量向更宽松处取点，观察面积和时延何时趋稳。 |

ASAP7 和 Nangate45 分别确定周期，保持各自的采样外壳、驱动／负载、ABC/SDC 和 GRT 标签口径。已测点与本轮请求及测量身份完全一致时可直接计入相应档位。可提取本体标签的 setup 违约点保留实测 WNS 与违约标记。超时、工具失败及标签缺失单独登记，并报告各档有效点数。512 位乘法先试测后端耗时和内存，再展开余下点位。 [数据与标签合同](models.md#数据与标签)

## 合并、拟合与验证

1. 从历史归档提取相容的算术及后续结构样本。按 RTL 源、工艺和流程身份、采样外壳、周期、标签阶段及提取合同核对并去重。记录来源文件与哈希，保留原始训练、验证、独立测试和已消费回归角色。把同一个源的所有周期放在同一数据分组。
2. 先在现有函数形式上用历史训练数据和新增训练数据联合校准，按源平衡权重。逐工艺、算子族、位宽和周期档报告面积及时延的有符号误差、绝对相对误差中位数和 P95。若固定结构的时延曲线仍有系统性偏差，再用训练和验证数据比较改过的特征或函数形式。
3. 用冻结的当前模型与校准后的候选模型对照，先看留出源，再对照同一批完整 RTL 的每级预测与 STA、总面积、紧周期下预测达标而实测违约的比例。固定候选池复算排序和选型，记录因价格改变而换选的方案。发布前运行相关的软件预测、功能和入口一致性回归，并据实更新精度资格及外推范围。 [精度与数据职责](models.md#精度与数据职责)

## 后续结构模型

沿用每个结构三档各 5 点、合并相容历史样本和按源留出的办法，依次校准 **G 归约、S 状态／控制、shared 共享开销**。G 按输出宽度、项数、位列稀疏和重叠采样，测区域本体时延和面积。S 按寄存器位数、使能负载、复位和跨级存续采样，测独占状态面积及各类控制路径所需时间。shared 按功能面积、FF 数、输入规模和复位负载采样，提取共享时钟、共享物理及根信号修复面积。G 使用本体查询周期，S 和 shared 使用完整请求周期。各分项校准后再验证完整候选。 [模型职责与响应形式](models.md#共享响应形式)
