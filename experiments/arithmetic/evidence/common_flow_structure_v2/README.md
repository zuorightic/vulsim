[通用特征](../../../arithmetic_dse/flow_structure_features_v4.py) 仅在零压缩且中间精度小于最终有效精度时使用串联深度风险；已有 vector compression 的 G 保留 fused 几何。条件来自图和数值位宽，不使用源 ID。Add 面积采用 KS 共同工作量响应，Mux 时延采用共享 load／log(T) 响应；二者参数继承 v2，在 v3／v4 没有重拟合。S 对同一条路径比较完整 R、delay+H、cell+wire+H，加入来源／capture 负载、reset 极性、word 分布和数值 T 交互；最后取银行最大值。仍用原 train 推导的非负 LP reserve，没有手工抬保护。
