四级加法包含四个活跃算术级；四级乘法采样包含三个活跃算术级与一个传递级，三级乘加覆盖中间级及跨级保存。本批没有独立的同结构换位置排序对照，不能把小组合精度或软件回放称为完整候选排序精度通过。
