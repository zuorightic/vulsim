# ASAP7 模板区间模型：完整首轮与独立测试失败检查点

本包继承 `step7_models_v1` 的四平台局部 grt 模型检查点，记录 ASAP7 原生乘法合法组区间的完整首轮采集、拟合与独立测试。**没有发布合格的区间模型，步骤七未完成。** 原有四平台普通局部模型的资格不因本轮区间模型失败而改写。

原准入共67个任务：28 train、18 validation、21 test，全部完成synth→grt；形成420行拟合／验证标签和168行独立测试标签。一个算术区间的两个阶段标签不是两个独立结构。测试宽度为20／28，拟合使用8／16／32、验证使用12／24。42个区间类别均通过原验证门槛，冻结后实际重拟合得到字节一致的候选及验证报告；独立测试不进入拟合或裕量选择。

原门槛逐区间执行。grt的`half/full/0/0`、`half/low/0/2`各为2／22，`half/low/1/1`、`quarter/full/0/0`各为3／22，均超过错误可行预测比例0.05。整体19／924不能替代逐区间门槛；这里的924来自84个实际区间样本×11个预算比例，不是924个独立结构。排序只比较同位宽／同结果语义的完整模板，未含状态／流水调度，也没有量化正式D的PPA收益。

本包引用父包的内容字节池，保留父冻结和被替换源码；新原始全文归档在本机ignored目录。默认核验重算验证裕量、独立质量、数据隔离、发布拒绝及模型参数不变；`--verify-external`进一步重算实际SDC、Q→D、面积、DFF边界及测试测量的selection-freeze绑定。远端持久留存仍未确认。
