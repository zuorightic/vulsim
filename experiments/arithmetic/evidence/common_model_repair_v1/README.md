## 实现与机制

G从Query重建word三输入压缩、常量消简和存活输出DAG，补FA／HA潜在共享cut、未配对逻辑、typed深度及直接输入AND几何。最终area为冻结Liberty原语工作量之和乘共享正值响应，delay为共享正值函数；只有两组全域系数，不读映射后的单元数或精确源身份。训练LOSO只作候选选择诊断，不能当独立成绩。宽稀疏512位train在1500ps面积误差由前继的大偏差改善至约9.7%，但73位失败仍在；不能以总体平均替代子域验收。

S保存的placement检查点显示变化已发生于布局阶段，cell、wire和H分别守恒。在线只使用逻辑控制源、各类sink、根输入使用分布、reset极性、状态规模及数值T，未使用真实buffer树或实测电容。若干恒定特征在拟合导出时有很大抵消系数；两次极小浮点不一致失败已保存，消费端改用稳定求和后严格核对通过。参数不改；下一轮仍须从train修正恒定／近恒定列的拟合条件，不能将数值恢复说成物理误差已修好。

已完成117次train／中间T算子价格、162次G价格及162次G特征、1055次S价格核对；S含45个train银行实现和505个真实placement×2服务上下文。最终验证的33算子／39G／21S请求再作同参数核对，共1427次价格核对。81项G改名／顺序不变检查及13项域外／非法连接／公共资格拒绝通过。505放置仍只证明发射前特征可提取，`actual_arithmetic_S_qualified=false`。

早期G回归曾因旧Query未补target_ps而误报覆盖失败；后继只修评价调用并保存原报告，没有更改模型或数值误差。前驱四线证据可继续回放，原49项生产冻结依赖逐项未变。
