## 第4步的证据和边界

便携输入`reuse-inputs.json.gz`包含177条原train记录、102条已消费验证记录，以及串联、并行、旁路各两个旧物理实现。另有6条缺少明确角色的Mux记录排除；原20个独立算子源保持锁定。全部279条组件记录均检查原平台／grt／SDC合同，256条可将slack与同一路径的算术段配对，23条保留原T价格但排除逆向窗口诊断。

逆向检查由观测路径计算本体窗口，再用冻结H及预测消费者反解等效T，调用未改参数的模型。观测窗口来自标签，因此这是逆向一致性诊断，不能称为未见嵌入实现的独立预测验证。多根中最接近原采样T的根只用于这项诊断；在线候选仍按冻结的有限多根评分规则选择。

分项仍存在失败，见`validation/detail-summary.json`。例如native_valid的源聚合median／P95为27.72%／40.86%，native_enable为24.58%／31.29%；shared_clock面积为18.07%／44.89%，shared_physical为25.20%／26.87%。input／output数据边界proxy、input_valid、write-enable及reset proxy也未过各自门槛。旧档案无法逐端口配对的控制路径明确使用银行最大值，并保留匹配限制。完整总量误差较小不能覆盖这些分项失败。

本批决定保留原参数。逆向子集和旧组合的结果不足以为S、shared或新嵌入外壳拟合修补项；需要相容的新增组件／组合证据后另立批次，不拿旧验证或九例应用最终PPA回填。现阶段结论是“转换与共享函数可执行、部分回归数值相容，完整资格仍有缺口”。

## 第5步的搜索与RTL

新增[原生接口](../../../../rtlzz/main/arithmetic_workload.cpp)导出`scheduling-units.json`，并允许提交绑定图字节SHA、T、L的完整放置表。编译器先检查端口、依赖和不可拆组，再经原有状态物化、owners和RTL发射。原CLI保留；90个旧候选重新原生生成后的图／放置／状态／目标化owners／RTL与冻结输入一致。

有限语法为乘法块宽`{0,4,8,12,16,24,32}`、加法limb宽`{0,16,32}`，每次结构扩展只改一个语法参数。模型及静态引导都使用完整阶段压力／面积的提案算法；结构提案先作近似响应估计，新候选的真实接受依据始终是原生重建后的完整评分。位置提案移动一个原生不可拆组一个阶段，透明连线重新取合法最早级。旧G价格只用于提案启发，实际候选重新发现G、生成预算、转换和完整计价，不继承父位置的查询。

每档每条策略均使用30个固定种子、3次结构扩展（每结构4个原生beam位置）、6次新位置扩展。因此各策略每档均评估48个候选。两条策略共用同一有限语法与额度，按完整图／位置／T去重后，500／750／1000ps分别有61／53／61个候选，共175个，其中90个固定候选、85个新候选。`search/search-events.json`保留全部结构提案排序、位置提案、依赖拒绝、重复和触限；语法没有被穷举，不声称全局最优。

静态控制使用同一个完整评分器及原train-only static bridge替换算术价格，保留实际S、shared、端口和控制责任。它是同策略归因控制，**不是最终九例C的后端结果**。全部候选同时用两套价格评分；`search/summary.json`保留两条策略各自在自己48个候选范围内的选择。最后将两条策略已完整评分的候选汇合，在同一共同池上比较两套价格，实际后备不会漏掉已知更快候选。

每个入选候选的实际预算、等效查询、状态、owners和RTL均来自同一完整评分快照。72份不同RTL（30份固定种子、42份新RTL）均重新运行192周期的独立整数／周期参考，共9,720个有效数据检查，覆盖复位、保持、独立输入写使能、valid和停顿。重复RTL只在字节及testbench哈希完全一致后共享仿真收据；目标相关的state／owners／预算／查询分别保存。原生probe会附带生成少量仅供取得合法组的beam RTL，它们未进入价格候选集，不能据此宣称已验收所有probe。

紧目标按完整违约优先，因此500／750ps选了更快、面积约增加22%的后备；宽目标在满足时钟的候选中优先面积，1000ps预测面积降低16.47%。500／750ps的更快新位置来自静态引导搜索，模型在共同池重新评分后选中。模型单独引导的同额度搜索在两档仍选8位块，分别预测819.754682ps／1121.037248µm²和836.890391ps／1101.185707µm²；这项差异暴露了有限提案启发的不足，不能把扩展共同池的收益全归因于模型。

软件选择不为每个算子设置实际局部ABC约束。等效T仍是模型的采样语义输入，实际实现合同保留全局T；局部请求是否对应整体内真实映射响应，须在后续有限物理评价中检验。本批没有新的面积、STA Tmin、频率或hold实测，尚不能称D优于B／C。

## 复现与文件

相关回归65项全部通过，包括原生模型绑定、显式放置的图／T／L／维数／范围／重复／固定端口／不可拆组拒绝，以及原来的预算、反解、完整计价和静态控制检查。编译目标为`rtlzz-workload`；仅编译器、Icarus及其运行时进入候选生成与验证，EDA命令以失败sentinel替换，最终标记审计为零次尝试。测试和隔离重算的具体收据见`verification.json`及`isolated-replay.json`。

```bash
# 原生接口的增量编译
cmake --build build/workload-v10-20261115 --target rtlzz-workload -j2

# 从便携源码和输入在临时目录重算；禁止读取原工作区／artifact，禁止启动子进程
python3 -B -m experiments.arithmetic_dse.workload_steps45_package replay

# 恢复完整原生工作产物到一个尚不存在的目录，不启动EDA
python3 -B -m experiments.arithmetic_dse.workload_steps45_package restore \
  --destination /tmp/vulsim-steps45-native-restored

# 65项相关回归，启用三个原生v10绑定检查
VULSIM_WORKLOAD_V10_BINARY="$PWD/build/workload-v10-20261115/rtlzz-workload" \
  python3 -m unittest regression.test_workload_guided_search \
  regression.test_workload_equivalent regression.test_workload_diagnostic \
  regression.test_workload_v10 regression.test_workload_abcd -v
```

`native-artifacts-*.gzpart`保存原生输出及首次搜索使用的源码，`replay-input-*.gzpart`保存175个候选的完整图／状态／查询／预算反馈轨迹；分块与成员均绑定SHA256。`software-source.json.gz`为可隔离重放的最终源码快照，包含归档／审计入口。工作大文件及两次开发失败完整移至`artifact-location.json`指定的`/home/zyrv/vulsim-artifacts/workload-equivalent-steps45-v1/`，没有删除；便携回放不依赖该目录。两个失败分别为testbench函数返回值的调用错误，以及被原生检查拒绝的常量输出valid错误放置，均已修正并补检查。

模型、原采样合同、冻结语法、源职责和失败分别保留。后续为第6步MAC32三档统一ABCD物理比较；若按现模型推进，应明确标为诊断对比，并保留局部响应／Mul→G／S／shared精度限制。之后仍需完成其余八例和九例19组目标的统一主表。
