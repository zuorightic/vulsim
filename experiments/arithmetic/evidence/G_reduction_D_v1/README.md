# G归约融合修正、函数验收与D RTL交付证据 v1

本轮已完成“通用G区域函数→与预测相容的RTL发射→重新D选择→实际RTL周期验证”。规划和实施记录见[现行计划§7.81](../../../../mission/lxy-plan-fix.md#G-reduction-fusion-successor)，函数见[G模型](../../models/asap7_G_reduction_v1/README.md)，公共调用见[新D依赖包](../../models/asap7_fused_D_prototype_v1/README.md)。完整持久产物根为`/home/zyrv/vulsim-artifacts/G-reduction-20261112-v1`，下文简称ROOT。

小算子函数继续负责独立Mul／Add，S负责实际状态、控制和寄存器边界。G中的`f_reduce`从真实图与placement发现语义安全的同级归约区域，用位列几何、进位跨度、压缩工作量／平衡层数和数值T整体预测其时延、组合面积。区域价格替换内部Add价格，内部连线和节点不重复计费，区域之间按DAG传播；功能面积变化后重新计算shared。整级50ps只加一次，区域外额外G残差为0。

模型为全局9个系数、其中7个非零的函数，没有源、MAC、候选、placement、精确shape或精确T编号的系数／价格表。区域发现和发射共用合同：内部发射规范化定宽多加数求和，允许联合综合，外部仍保留层次。不是仅降低预测而继续发射逐Add保层次RTL。

首版融合域为无符号、同级、寄存器／服务输入发起、变量位无重复纯别名、单个实际capture银行的归约。输入移位／补零按真实位连接提取；内部截断后扩展必须证明模语义安全。共享内部值、多capture、非低位中间slice、同级Mul输入及非零常量等保持原节点边界。已判定可融合但区域模型缺覆盖时明确拒绝。数值范围为T=500–3000ps、输出需求16–96位、3–17个live加数，实际支持是全部数值和语义规则的交集，不保证整个矩形域任意连接均被接收。

## D选择、RTL及通用性

新D复用原选择规则：完整覆盖时，有预测可行解取最小总面积；全部违约取最大时序违约最小者，面积打破并列；候选缺覆盖或枚举不全均不发射。下面为模型结果，周期列包含一次50ps整级预留，**不是新入选RTL的后端实测Tmin**；非算术路径另按S保护。

half/view5为第一级4个16×16、第二级移位归约；quarter/view7为第一级16个8×8、第二级17加数归约。1500ps选择original符合满足目标后面积最小的规则，没有强制偏好拆分。各份`D.sv`、`D_core.sv`、完整Query／分项价格／区域合同及逐候选轨迹位于ROOT的`outputs/T*/`。

190项生产与候选Python／C++推理核对为184覆盖／6拒绝。五T共220候选、3440原节点描述、30个区域报价和7905条位连接，以及S、shared、最终排序均由独立Python复算通过。每T的36个内部Add由区域替换，未重复计费。后继`FactoredStateBoundaryProvider`复用原S投影和系数，仅输出S项，避免旧S包装器预先要求内部Add／shared价格；故意收窄内部Add域后half仍由G完整报价，其他未覆盖候选则触发整次拒绝。

14项区域合同及7项D拒绝检查通过，包含不安全截断、重复纯位别名、中间共享值、寄存器切断、多capture、域外T、未独立候选、枚举不全、部分覆盖、源身份和输出目录保护。合同测试发现过“多个capture银行合并为单逻辑端点”的误收，已在参数／实现冻结和独立评价前修正为检查实际Query的银行数，原失败保留。

5份入选RTL、当前44放置和1个新纯加法图，共50份执行各256周期／8100次有效数据比较通过。覆盖独立服务写使能、held-valid、气泡、溢出、非零／在途功能reset和native FF保持。新图无Mul、只有4个合法放置；固定同一模型、支持规则和选择器，在1373ps选择`candidate/view0`、预测面积262.264675um²，独立数值及周期验证通过，没有新增该图物理测量。当前44候选仅作有限搜索回归集。公共入口封存后再次执行1000ps，选择及RTL字节一致。
