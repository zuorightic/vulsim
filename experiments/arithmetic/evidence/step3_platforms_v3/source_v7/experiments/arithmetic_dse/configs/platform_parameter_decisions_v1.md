# 平台接通参数的来源与适用范围

本记录补充解释已在backend v5/v6冻结的四个平台profile，不改变任何有效值。它是对项目工程选择的追溯说明，不冒充此前未记录的PDK规定。机器可读逐项表见同目录`platform_parameter_sources_v1.json`；原文件身份和有行号的摘录见`../../arithmetic/evidence/step3_platforms_v3/parameter_source_excerpts.json`。

## D1 时钟假设

ASAP7的20ps setup uncertainty、5ps hold uncertainty、10ps transition及5ps hold复核带继承原ASAP7实验。Nangate45在首轮平台接通中沿用20/5/10/5ps；Sky130HD和GF180采用100/25/100/25ps。后面三者是项目接通试跑的工程约定，并无本轮已找到的独立PDK标准值或噪声校准证据。采用不同绝对假设以覆盖较慢平台的接通场景，并保持setup与hold分开；不能将这些比例表述为经硅验证的jitter、CTS精度或跨工艺公平性证明。hold带只触发人工工程复核，不改变grt可行性门限，不等于数值噪声底。

## D2 I/O 环境

默认输入/输出max delay均为各自试跑周期的20%，min为0，使用io_clk；reset、valid、数据都覆盖。显式`io_delay_max_ps`作为另一个请求轴覆盖max策略。这继承原后端试验的虚拟I/O壳，未声称有真实封装/板级时序来源。driver cell优先沿用所选ORFS平台的ABC driver，pin来自对应库的输出接口；它描述输入驱动环境，不能替代完整上游时序模型。输出负载和ABC负载均显式以fF记录，分别进入STA与ABC，并核对各自单位。

ASAP7、Nangate45的3.898fF及Sky130HD的5fF沿用ORFS默认。GF180选13.43fF统一本项目输出与ABC环境；ORFS原`ABC_LOAD_IN_FF=0.01343`的数值不同，本项目使用的是显式覆盖，并非原默认。ABC读取Liberty后将负载归一为fF，源码身份已记录；13.43fF本身仍是既有项目试跑选择，没有找到“PDK规定必须取该值”的依据。write_sdc四位小数会把0.01343pF序列化为0.0134pF；当前核验明确记录此舍入，不声称逐位数值完全相等。

## D3 试跑周期

ASAP7 1500ps继承既有接通探针；Nangate45 3000ps、Sky130HD/GF180 30000ps是事先冻结的工程试跑目标。选择意图是完成小核及共同32位乘法的流程接通，不是正式案例目标推导、最佳频率或模型训练域。ABC target与SDC period分别保存；本批两轴取相同数值，不代表两者等价。没有按后验slack换周期。

## D4 适用范围与变更影响

上述参数仅已验收于四平台TT/typical接通探针、L=3、II=1及各自冻结工具/库/RC上下文，`multi_corner_signoff=false`。它们没有直接确立训练域或43例/688条正式评价环境。后续训练/评价需重新声明环境、目标与模型域；不能把接通结果自动纳入训练或目标标签。

仅修改本来源说明或侧表会改变**来源元数据身份**，不改变profile内容身份、有效配置或物理测量。改变uncertainty、transition、I/O、driver、load或试跑目标则改变测量条件：先记录受影响轴、旧结果适用边界及模型/标签兼容性，再按既有预算准入重验。改变hold复核带需重算风险标记；若它仅用于报告，不因此自动重跑EDA，也不得改写历史标记。改变RC系数属于实际物理行为变化，不能通过“补说明”实施。

## D5 GF180 wire RC待核项

本地ORFS提交`dc4c579129d00ef56db02124b2b542346b1ca54e`称线阻更新来自segment-based regression；更早`de7739cc5ea745132afd7e60c19abb6e7c71d413`列出五个设计。现有相关脚本的电阻输出默认单位是kohm/µm，而所选Liberty及实际STA报告为1ohm。尚未找到该提交实际使用的命令、原始segments、回归结果与输出单位，因此不能从默认值反推该提交一定用了kohm，也不能断言现有系数已证实错误。

LEF名义方阻除以名义宽度，与回归的有效线阻不必严格相同：实际宽度、选中线段/长度、几何和提取拟合方法均可能不同；这些可能性并未闭合当前量级差异。风险登记为**来源部分闭合、物理量级校准未闭合**。保持原wire系数与RCX规则；Via1–Via4单孔4.5Ω的检查只验证通孔适配，不证明wire RC全部正确。

后续进入GF180训练或正式评价前，应找回匹配提交的校准命令/单位/数据，或另行准入有限代表线段与grt估计/提取对照，确认长度、线宽、单位及电阻口径；若确认需修改系数，建立新profile/模型域及受影响重验。此次仅记录风险，不启动物理调用，也不凭猜测乘1000。
